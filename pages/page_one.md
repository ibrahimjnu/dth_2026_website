# Open Source Software and its Advantages

## Open Source Software

Open-source software is a kind of software that makes its source code publicly accessible so that people can inspect, change, and develop its code and can contribute to its future upgradation. Users can also modify the software as they need it for their task-oriented purposes. For example: LibreOffice. Opensource.com defines it this way: *“Open source software is software with source code that anyone can inspect, modify, and enhance.”*



## Advantages of Open Source Software

Open-source software allows the users to check and read the source code. There are a lot of advantages to open-source software.


### Control over the Software ### 

As the source code of open-source software is available and editable by users, they can control the software or the program on what activities and tasks the software can do and what it cannot do. In open-source software people can also customize their software depending on their business, and they are not bound to be stuck on the version built by the creator. For example, Android is open source, so phone makers can take its code and change it to build their own version for their phones.


### Transparency ###

Users have access to the software source code, so they can check the software's access limit to their data and files. With proprietary software, users cannot check what happens to their data. So there is a potential threat of data leakage.


### Community Buildup ###

 Programmers who work on developing the software share their software codes with others. Other programmers join in the updating and upgrading process. In this way they build up a community that helps each other in developing software.
