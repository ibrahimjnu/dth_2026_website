# Disadvantages of Open Source Software



## Lack of Official Support

Open source software often has no official support service. When users have a problem, they usually have to ask volunteers in forums or on GitHub and wait for an answer. Therefore, in urgent situations, it can be difficult to find a solution quickly. For example, the data analysis tool Orange had 102 open issues on GitHub in November 2026, which means 102 problems or questions were still waiting to be solved.

## Safety and Security

In an open source system, the source code is publicly accessible. Hackers also have the opportunity to study the code, find its weak points, and attack software and websites that use it. In this way, they can get access to sensitive personal and organizational data. A very recent example is PHP2Shell. In October 2026, two critical security holes were found in PHP, an open source programming language used by many websites. Because of this threat, the central bank of Bangladesh, Bangladesh Bank, shut down its website for three days to keep it safe.

## Vendor Support Issue

Open source software can cause problems with the vendors of other software. A vendor is a company that sells software and promises to help its customers when something goes wrong. If the vendor has not approved the open source software in advance, and a problem arises, the vendor can refuse to solve it, because the software was not approved by them. For example, if a company pays Oracle for support of its database and adds an open source tool to it without Oracle’s approval, Oracle may refuse to help when the database stops working.
